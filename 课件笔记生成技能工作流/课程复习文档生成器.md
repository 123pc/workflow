# 课程复习文档生成器

## 概述

本技能将课程原始课件一键转化为高质量、结构化、图文并茂的考试复习文档（Markdown格式）。输出质量对标"DSP期中复习完全指南"——包含阅读指南、核心思维导图、概念精讲、完整公式推导、例题详解、公式速查卡、解题模板和常见错误附录，关键概念配以课件原图辅助理解。**对于课件中公式显示不全或推导步骤跳跃的地方，AI助手会自动补全缺失的推导步骤，确保公式完整可读、推导逻辑连贯。**

---

## Phase 1: 信息收集与范围确认

### 1.1 确认课件位置

向用户询问课件文件所在的目录路径。如果用户没有明确提供，请用户将课件文件（.pdf/.pptx/.docx）放入一个目录中。

### 1.2 扫描课件文件

使用 Glob 或 Bash(`ls`) 扫描该目录，列出所有 `.pdf`、`.pptx`、`.docx` 文件。以表格形式呈现给用户，包含文件名和大小。

### 1.3 确认考试范围

向用户逐项确认以下信息：

1. **考试范围**：哪些章节/讲座在考试范围内？哪些明确不在？（例如："L1-L14，不包含L11"）
2. **课程全称**：中文全称和英文全称（如有）
3. **授课教师**：姓名和单位
4. **参考教材**：书名、作者、版本
5. **考试形式**：闭卷/开卷/半开卷
6. **授课语言**：中文授课/英文授课/双语授课
7. **输出文件名**：用户期望的输出 .md 文件名（如"流体力学_期末复习_终极版.md"）

### 1.4 创建输出目录

在课件所在目录下创建 `extracted_text/` 和 `extracted_images/` 两个子目录。

---

## Phase 2: 课件内容提取（文本 + 图片）

### 2.1 提供提取脚本

向用户说明：需要先用脚本把课件中的文本和图片同时提取出来。让用户将下方脚本保存为 `extract_course_materials.py` 放在课件目录下，修改配置区路径后运行。

脚本功能：
- **文本提取**：将所有页面的文字提取为 `.txt` 文件，存入 `extracted_text/`
- **图片提取**：将课件内嵌的所有图片导出，按 `{课件名}_p{页码}_img{序号}.{格式}` 命名，存入 `extracted_images/`
- **占位标记**：在文本中插入 `[图片: xxx.png]` 标记，精确记录每张图片在课件中的位置
- **依赖自检**：启动时检测 `pypdf`/`python-pptx`/`python-docx` 是否安装，缺失则给出安装命令

```python
"""
课程课件内容提取工具 —— 文本 + 图片
支持格式: .pdf (pypdf), .pptx (python-pptx), .docx (python-docx + zipfile)
所有依赖均为纯Python库，pip一键安装，无C编译依赖。

使用方法:
  1. 修改下方"配置区"的 课件目录、文本输出目录、图片输出目录
  2. 运行: python extract_course_materials.py
"""

import os
import sys
import zipfile
from pathlib import Path

# ============================================================
# 0. 依赖自检
# ============================================================
MISSING = []
try:
    from pypdf import PdfReader
except ImportError:
    MISSING.append("pypdf")
try:
    from pptx import Presentation
    from pptx.enum.shapes import MSO_SHAPE_TYPE
except ImportError:
    MISSING.append("python-pptx")
try:
    from docx import Document
except ImportError:
    MISSING.append("python-docx")

if MISSING:
    print("=" * 50)
    print("以下 Python 库未安装，请先运行：")
    print(f"  pip install {' '.join(MISSING)}")
    print("=" * 50)
    sys.exit(1)

# ============================================================
# 1. 配置区 —— 用户根据需要修改以下变量
# ============================================================
课件目录 = r"课件"               # 课件所在目录路径
文本输出目录 = r"extracted_text"   # 提取文本输出目录
图片输出目录 = r"extracted_images" # 提取图片输出目录

os.makedirs(文本输出目录, exist_ok=True)
os.makedirs(图片输出目录, exist_ok=True)

# ============================================================
# 2. 工具函数
# ============================================================

def _content_type_to_ext(content_type):
    """将 MIME content-type 映射为文件扩展名"""
    mapping = {
        "image/png":  ".png",
        "image/jpeg": ".jpg",
        "image/gif":  ".gif",
        "image/bmp":  ".bmp",
        "image/tiff": ".tiff",
        "image/webp": ".webp",
        "image/x-png": ".png",
        "image/x-emf": ".emf",
        "image/x-wmf": ".wmf",
    }
    return mapping.get(content_type, ".png")


def _guess_ext_from_bytes(data):
    """通过文件头魔术字节推断图片扩展名"""
    if data[:4] == b'\x89PNG':
        return '.png'
    if data[:2] == b'\xff\xd8':
        return '.jpg'
    if data[:4] == b'GIF8':
        return '.gif'
    if data[:2] == b'BM':
        return '.bmp'
    if data[:4] == b'RIFF' and data[8:12] == b'WEBP':
        return '.webp'
    return '.png'


def _sanitize_filename(s):
    """移除文件名中的非法字符"""
    illegal = '<>:"/\\|?*'
    for c in illegal:
        s = s.replace(c, '_')
    return s


# ============================================================
# 3. 格式提取函数 (文本 + 图片)
# ============================================================

def extract_pdf(filepath, basename):
    """提取 PDF 文本和图片"""
    reader = PdfReader(filepath)
    lines = []
    img_count = 0

    for i, page in enumerate(reader.pages):
        page_num = i + 1

        # --- 文本 ---
        text = page.extract_text()
        if text and text.strip():
            lines.append(f"\n--- 第{page_num}页 ---")
            lines.append(text)

        # --- 图片 ---
        try:
            for j, img_obj in enumerate(page.images):
                img_data = img_obj.data
                if not img_data or len(img_data) < 100:
                    continue
                ext = _guess_ext_from_bytes(img_data)
                img_name = f"{basename}_p{page_num}_img{j+1}{ext}"
                img_path = os.path.join(图片输出目录, img_name)
                with open(img_path, "wb") as f:
                    f.write(img_data)
                lines.append(f"[图片: {img_name}]")
                img_count += 1
        except Exception:
            pass

    return "\n".join(lines), len(reader.pages), img_count


def extract_pptx(filepath, basename):
    """提取 PPTX 文本和图片"""
    prs = Presentation(filepath)
    lines = []
    img_count = 0

    for i, slide in enumerate(prs.slides):
        slide_num = i + 1
        slide_texts = []

        for shape in slide.shapes:
            # --- 图片 ---
            if shape.shape_type == MSO_SHAPE_TYPE.PICTURE:
                try:
                    img_blob = shape.image.blob
                    if img_blob and len(img_blob) >= 100:
                        ext = _content_type_to_ext(shape.image.content_type)
                        img_name = f"{basename}_s{slide_num}_img{img_count+1}{ext}"
                        img_path = os.path.join(图片输出目录, img_name)
                        with open(img_path, "wb") as f:
                            f.write(img_blob)
                        slide_texts.append(f"[图片: {img_name}]")
                        img_count += 1
                except Exception:
                    pass

            # --- 文本框 ---
            if shape.has_text_frame:
                for para in shape.text_frame.paragraphs:
                    t = para.text.strip()
                    if t:
                        slide_texts.append(t)

            # --- 表格 ---
            if shape.has_table:
                table = shape.table
                for row in table.rows:
                    row_texts = []
                    for cell in row.cells:
                        ct = cell.text.strip().replace("\n", " ")
                        row_texts.append(ct)
                    slide_texts.append(" | ".join(row_texts))

        if slide_texts:
            lines.append(f"\n--- 第{slide_num}张幻灯片 ---")
            lines.append("\n".join(slide_texts))

    return "\n".join(lines), len(prs.slides), img_count


def extract_docx(filepath, basename):
    """提取 DOCX 文本和图片 (图片通过 zipfile 从 word/media/ 提取)"""
    doc = Document(filepath)
    lines = []
    img_count = 0

    # --- 文本 (通过 python-docx) ---
    for para in doc.paragraphs:
        t = para.text.strip()
        if t:
            lines.append(t)

    for ti, table in enumerate(doc.tables):
        lines.append(f"\n[表格 {ti+1}]")
        for row in table.rows:
            row_texts = []
            for cell in row.cells:
                ct = cell.text.strip().replace("\n", " ")
                row_texts.append(ct)
            lines.append(" | ".join(row_texts))

    # --- 图片 (通过 zipfile 从 docx 内部提取) ---
    try:
        with zipfile.ZipFile(filepath) as z:
            media_files = [n for n in z.namelist() if n.startswith("word/media/")]
            for idx, media_path in enumerate(media_files):
                img_data = z.read(media_path)
                if not img_data or len(img_data) < 100:
                    continue
                original_name = os.path.basename(media_path)
                ext = os.path.splitext(original_name)[1].lower()
                if ext not in ('.png', '.jpg', '.jpeg', '.gif', '.bmp', '.tiff', '.webp'):
                    ext = _guess_ext_from_bytes(img_data)
                img_name = f"{basename}_img{idx+1}{ext}"
                img_path = os.path.join(图片输出目录, img_name)
                with open(img_path, "wb") as f:
                    f.write(img_data)
                lines.append(f"[图片: {img_name}]")
                img_count += 1
    except Exception:
        pass

    return "\n".join(lines), len(doc.paragraphs), img_count


# ============================================================
# 4. 扫描并提取
# ============================================================
HANDLERS = {
    ".pdf":  extract_pdf,
    ".pptx": extract_pptx,
    ".docx": extract_docx,
}

目标文件 = []
for fname in sorted(os.listdir(课件目录)):
    ext = os.path.splitext(fname)[1].lower()
    if ext in HANDLERS:
        目标文件.append(fname)

if not 目标文件:
    print(f"在 '{课件目录}' 中未找到 .pdf/.pptx/.docx 文件，请检查路径。")
    sys.exit(1)

print(f"找到 {len(目标文件)} 个课件文件，开始提取文本和图片...\n")

总图片数 = 0
成功 = 0
失败 = []
空内容 = []

for idx, fname in enumerate(目标文件, 1):
    filepath = os.path.join(课件目录, fname)
    ext = os.path.splitext(fname)[1].lower()
    basename = _sanitize_filename(Path(fname).stem)
    handler = HANDLERS[ext]

    try:
        text, page_count, img_count = handler(filepath, basename)
        header = f"======= {fname} =======\n页数/幻灯片数: {page_count}\n" + "=" * 60

        if text.strip():
            outpath = os.path.join(文本输出目录, fname + ".txt")
            with open(outpath, "w", encoding="utf-8") as f:
                f.write(header + "\n" + text)
            成功 += 1
            总图片数 += img_count
            img_info = f", {img_count}张图片" if img_count else ""
            print(f"  ✓ [{成功}/{len(目标文件)}] {fname} ({page_count}p{img_info})")
        else:
            空内容.append(fname)
            print(f"  ⚠ [{成功}/{len(目标文件)}] {fname} — 提取内容为空")
    except Exception as e:
        失败.append((fname, str(e)))
        print(f"  ✗ [{成功}/{len(目标文件)}] {fname} — 错误: {e}")

# ============================================================
# 5. 结果报告
# ============================================================
print(f"\n{'=' * 50}")
print(f"提取完成: 成功 {成功}/{len(目标文件)}, 共提取 {总图片数} 张图片")
print(f"  文本目录: {os.path.abspath(文本输出目录)}")
print(f"  图片目录: {os.path.abspath(图片输出目录)}")

if 空内容:
    print(f"\n⚠ 以下文件提取内容为空 ({len(空内容)}个):")
    for fn in 空内容:
        print(f"  - {fn}")
    print("可能原因：PDF是扫描版（图片） / PPTX/DOCX只含图片不含文字。")
    print("建议：对于扫描版PDF，直接让Claude读取PDF图片进行识别；")
    print("      对于纯图片PPTX/DOCX，手动提取文字或使用OCR工具。")

if 失败:
    print(f"\n✗ 以下文件提取失败 ({len(失败)}个):")
    for fn, err in 失败:
        print(f"  - {fn}: {err}")

if not 空内容 and not 失败:
    print("所有文件提取成功！")
```

### 2.2 运行提取

让用户运行 `python extract_course_materials.py`。

脚本会输出类似以下报告：

```
找到 13 个课件文件，开始提取文本和图片...

  ✓ [1/13] chapter1_L1_introduction.pdf (45p, 12张图片)
  ✓ [2/13] chapter2_L3_review.pdf (30p, 8张图片)
  ...

==================================================
提取完成: 成功 13/13, 共提取 156 张图片
  文本目录: C:\...\extracted_text
  图片目录: C:\...\extracted_images
```

如果出现错误或空内容，按脚本输出的提示给出解决方案：

- **pypdf提取质量差**：建议切换到 pdfplumber（`pip install pdfplumber`）
- **文件损坏**：请用户检查原始文件

### 2.3 读取提取结果

提取成功后，你需要：

1. **逐一读取** `extracted_text/` 目录下的所有 .txt 文件，理解全部课件内容
2. **浏览图片** `extracted_images/` 目录，了解有哪些可用的图表资源
3. 对于内容较长的课件（>2000行），使用分段读取（offset + limit）确保不遗漏

## Phase 3: 生成图文并茂的V3终极版复习文档

基于你对全部课件文本和图片的深入理解，一次性生成最终复习文档。

### 3.1 文档生成原则

**在动笔之前**，先完成以下思考：

1. 这门课程的核心主线是什么？（一条贯穿始终的逻辑链）
2. 哪些概念是"基石"（后续概念依赖它）？
3. 哪些公式/定理是考试必考？（反复出现，所有例题都用到）
4. 学生在哪些地方最容易混淆？（相似但不同的概念）
5. 典型考题有哪几类？（每类对应一种解题模板）
6. **哪些图片是关键图表**？（课件中的核心示意图、公式推导图、流程图——它们比文字更直观，必须引用到文档中）
7. **哪些公式在课件中显示不完整**？（PDF文本提取可能导致公式断裂、符号丢失——动笔前逐一核对每个公式是否完整）
8. **哪些推导步骤被省略了**？（课件中常有"易证""显然""由此可得"跳过中间步骤——你需要在文档中补全这些逻辑跳跃）

### 3.2 图片引用策略

图片能让复习文档从"能看"变成"好用"。按以下原则处理图片：

**必须引用的图片类型**（优先使用课件原图）：
- 核心概念示意图（如系统框图、信号流程图、物理模型图）
- 关键公式的图解推导（如几何解释、坐标变换示意图）
- 对比图（如正确vs错误、变换前vs变换后）
- 解题流程图（如算法步骤图、决策树）

**不需要引用的图片类型**：
- 纯装饰性图片（背景、图标、装饰元素）
- 与文字内容完全重复的简单公式截图
- 分辨率过低、无法辨认的图片

**引用方式**：在 Markdown 中使用相对路径

```markdown
![描述文字](extracted_images/课件名_p3_img1.png)
```

**引用位置**：
- 在 6步概念模板 的第2步"定义"之后插入相关示意图
- 在第4步"💡直觉理解"中引用图解辅助理解
- 在第5步"✏️例题"中引用解题流程图
- 在第0章"课程核心思维"中使用课件中的核心框图

### 3.3 公式还原与推导补全

课件文本提取后，公式和推导常常出现以下问题，你必须主动识别并修复：

#### 3.3.1 公式完整性检查与还原

**常见公式提取问题及修复策略**：

| 问题类型 | 表现 | 你的修复方式 |
|---------|------|------------|
| 公式断裂 | 多行公式被拆成碎片、上下标错位 | 根据数学常识还原为完整LaTeX |
| 符号丢失 | 积分号∫、求和号∑、希腊字母变成乱码或消失 | 根据上下文推断正确符号 |
| 分数线丢失 | `a/b` 本应是 `\frac{a}{b}` | 识别并重写为标准LaTeX分数形式 |
| 上下标错位 | `x2` 本应是 `x^2` 或 `x_2` | 根据公式含义判断正确的上下标位置 |
| 矩阵/行列式混乱 | 矩阵元素排列错乱 | 根据线性代数规则重新排列 |
| 特殊函数名混淆 | `sin`、`cos`、`lim` 没有正确格式化 | 统一写为 `\sin`、`\cos`、\lim` |

**公式还原原则**：
1. **优先相信课件原意**：根据上下文和公式的物理/数学含义推断正确形式，而非机械照搬提取文本
2. **交叉验证**：同一公式出现在多页课件中时，对比不同位置的版本，取最完整的
3. **教材对齐**：核心公式的写法应与教材保持一致（符号、下标命名等）
4. **标注不确定处**：如果某个公式的符号实在无法确定，在文档中用 `<!-- 待确认 -->` HTML注释标注

#### 3.3.2 推导步骤补全

课件中的推导常常省略中间步骤（"易证""显然""由此可得"），这让学生无法独立复现。你必须补全所有被跳过的逻辑步骤。

**需要补全推导的场景**：

| 课件写法 | 你需要展开为 |
|---------|-----------|
| "易证得..." | 写出完整的证明/推导过程，至少3-5步 |
| "显然..." | 明确写出"显然"背后的逻辑链条 |
| "由此可得..." | 写出从上一行到下一行的具体代数操作 |
| "代入可得..." | 写出代入的具体表达式和化简过程 |
| 只有公式结果没有推导 | 从定义出发补全完整的推导链 |
| 关键步骤只有一行公式 | 在两行公式之间添加中间变换步骤和文字解释 |

**推导补全的格式规范**：

```markdown
🔑 **推导**: [定理名/公式名] 的完整推导

从 [起点公式/定义] 出发：

**第1步**：[操作描述]
$$[中间表达式1]$$

**第2步**：[操作描述——解释这一步做了什么、为什么这样做]
$$[中间表达式2]$$

**第3步**：[操作描述]
$$[中间表达式3]$$

...

**最终结果**：
$$\boxed{[最终公式]}$$

> 💡 **推导要点**：[总结这个推导中最关键的技巧或最容易出错的地方]
```

**推导补全原则**：
1. **每一步都要有文字解释**：不能只写公式——每步都说明"做了什么"和"为什么这样做"
2. **关键技巧要标注**：如果某步用到了特殊技巧（如配方法、变量代换、分部积分），明确标注
3. **假设条件要列出**：推导中的每一步写明其成立的前提条件
4. **最终结果要\boxed{}**：推导终点是考试要用的公式，用方框突出
5. **常见错误要提醒**：推导中最容易出错的地方加 `⚠️` 警告

#### 3.3.3 判断哪些推导需要补全

不是所有省略都需要补全。使用以下优先级：

| 优先级 | 补全范围 | 说明 |
|--------|---------|------|
| 🔴 必须补全 | 考试必考公式的推导 | 课件中常以"易证"跳过，但考试可能要求独立推导 |
| 🔴 必须补全 | 从基本定义到核心定理的推导 | 这是课程逻辑的主干，缺一步学生都跟不上 |
| 🟡 建议补全 | 例题中的计算步骤 | 课件常只给结果不给过程，补全后学生才能独立做题 |
| 🟡 建议补全 | 不同概念之间的衔接推导 | 帮助学生建立知识网络 |
| 🟢 可选 | 纯代数化简的每一步 | 如果只有加减乘除、移项等，不需要无限展开 |
| ⚪ 不需要 | 教材中有完整推导的内容 | 只需引用教材页码，避免文档冗余 |

### 3.7 质量确保标准

生成文档时，逐一对照以下12条标准进行自检：

1. **双语精确性**：所有关键技术术语同时给出中文和英文（匹配教材用语）

2. **数学排版**：所有公式使用标准LaTeX语法，重要最终结果用 `\boxed{}` 框出；inline用 `$...$`，display用 `$$...$$`

3. **公式完整性**：课件提取后的每个公式必须逐一检查——断裂的拼接完整、丢失的符号补回、错位的上下标修正、被截断的分数线还原为标准LaTeX分数形式。不能机械照搬提取文本中的公式残片。

4. **推导补全**：课件中所有被"易证""显然""由此可得"跳过的推导步骤必须补全。每步推导有文字解释（做了什么 + 为什么这样做），关键技巧明确标注，最终结果\boxed{}。补全后的推导让学生关上课件也能独立复现。

5. **分层解释**：每个核心概念至少包含三层——精确的数学定义 → 配图示意 → 💡直觉块引用 → ✏️计算示例

6. **图文并茂**：关键概念配有课件原图辅助理解。图片引用使用正确的相对路径 `extracted_images/xxx.png`。每个核心概念至少配1张相关图片，每章至少3张图片。图片不被滥用——装饰性图片不引入。

7. **深度脚手架**：读者可以从上到下层层深入——先读frontmatter知道范围 → 读第0章建立大局观 → 按图标速览核心概念 → 精读章节细节（图文对照）→ 用附录快速检索

8. **多遍阅读设计**：图标标记使读者可以只扫📌快速过一遍核心概念，也可以逐章精读

9. **学生同理心**：预判易混淆点（用对比表格+对比图澄清）；提供记忆口诀（中文短句）；用日常比喻建立直觉

10. **考试实用主义**：在关键考点旁标注"考试必考"或"考试重点"；附录B提供标准题型的算法化解题步骤；附录C列出学生最常犯的错误及正确做法

11. **统一视觉语言**：章节标题统一使用 `## 第N章：[标题]`；小节标题统一使用 `### N.M [标题]`；所有对比表格使用标准Markdown表格格式；所有直觉解释使用 `> 💡` 块引用；所有推导使用 `📐 **推导**` 标题；所有关键公式使用 `\boxed{}`

12. **丰富内容类型**：确保文档包含以下多种内容类型——表格（概念对比、性质汇总、公式速查）、公式块（定义式、推导过程、性质）、图片引用（示意图、流程图、对比图）、📐完整推导（补全步骤+文字解释）、✏️例题（分步骤讲解）、💡直觉块引用、ASCII框图（展示核心主线）、列表（步骤、性质、要点）

### 3.8 输出

生成复习文档后，将其保存到用户指定的文件名（默认为课件目录下的 `[课程名]_复习_终极版.md`）。

向用户报告文档统计信息：总行数、章节数、例题数、公式数（近似）、补全的推导数、引用图片数、附录条目数。

## 特殊场景处理

### 数学公式密集的课程
- 优先保证公式的准确性和完整性——公式是这类课程的生命线
- 课件文本提取后公式损坏率最高，逐一核对每个公式是否完整
- 每个重要公式附带完整的推导过程（📐）和一行文字说明其物理意义
- 附录A的公式速查卡需要格外详尽，按主题和用途双重索引
- 重点引用公式推导的图解图片
- **核心定理的推导必须100%补全**——这是学生"看懂公式"和"会用公式"之间的桥梁

### 概念记忆为主的课程
- 增加对比表格（相似概念并列对比）
- 附录C的常见错误条目需要更丰富
- 多使用记忆口诀
- 重点引用概念关系图和思维导图

### 编程/实践类课程
- 解题模板可使用代码块展示算法流程
- 附录B可包含代码模板
- 常见错误可包含典型bug
- 重点引用架构图、流程图、界面截图

### 课件质量差/内容缺失
- 如实标注内容不完整的章节
- 建议用户补充材料
- 不要编造内容填补空缺
- 对于纯图片课件：直接读取原始课件图片进行内容识别，不依赖文本提取

### 扫描版PDF（纯图片PDF）
- 跳过文本提取，直接逐页读取PDF图片
- 你具备多模态视觉能力，可以从图片中直接读取公式和文字
- 提取出的图片既是文本来源也是配图资源
