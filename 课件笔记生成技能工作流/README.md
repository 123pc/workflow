# 课程复习文档生成器

一键将课程原始课件（PDF/PPTX/DOCX）转化为图文并茂、公式完整、推导详尽的考试复习文档。

## 效果预览

**输入**：老师发的课件文件（任意格式混合）

```
课件/
├── 第1章_流体性质.pptx
├── 第2章_流体静力学.pdf
├── 第3章_伯努利方程.docx
└── ...
```

**输出**：一份结构化的复习文档（Markdown格式，可直接导出PDF）

```
# 🎓 流体力学 期末复习完全指南

📖 阅读指南
目录
第〇章：课程核心思维
第一章：流体性质 (📌核心概念 + 📐完整推导 + ✏️例题)
...
附录A：公式速查卡
附录B：解题模板
附录C：常见错误与陷阱
```

## 三步使用法

### 第一步：准备环境（仅首次）

打开终端，安装三个纯Python库（一次性操作）：

```bash
pip install pypdf python-pptx python-docx
```

把本目录下的两个文件复制到你的课程目录：

```
你的课程目录/
├── 课件/                          ← 你的课件放这里
├── 课程复习文档生成器.md           ← 技能文件
└── extract_course_materials.py    ← 提取脚本
```

### 第二步：提取课件内容

在终端中运行：

```bash
python extract_course_materials.py
```

脚本会自动：
- 扫描 `课件/` 目录下的所有 PDF、PPTX、DOCX
- 提取文本到 `extracted_text/`
- 提取图片到 `extracted_images/`
- 报告每个文件的提取结果

输出示例：

```
找到 8 个课件文件，开始提取文本和图片...

  ✓ [1/8] 第1章_流体性质.pptx (45p, 15张图片)
  ✓ [2/8] 第2章_流体静力学.pdf (32p, 10张图片)
  ...

==================================================
提取完成: 成功 8/8, 共提取 127 张图片
```

> 如果某些文件提取内容为空（通常是扫描版PDF），脚本会给出提示。
> 不用担心，Claude Code 可以直接读取PDF中的图片来识别内容。

### 第三步：让Claude Code生成复习文档

在当前目录下打开 Claude Code，输入触发词即可：

> "帮我整理流体力学期末复习文档"

或者：

> "把这些课件生成复习指南"

Claude Code 会自动加载技能文件，依次执行：

1. **信息收集** — 问你考试范围、教材、考试形式
2. **内容分析** — 读取所有提取的文本和图片，深入理解课程内容
3. **生成文档** — 一次性产出终极版复习文档

你只需要回答几个问题，剩下的全部自动完成。

## 常见问题

### Q: pip安装库时报错？

请确认Python版本 ≥ 3.8：

```bash
python --version
```

如果版本过低，去 [python.org](https://www.python.org/downloads/) 下载最新版。

### Q: 课件是扫描版PDF，提取不出文字？

脚本会提示"提取内容为空"。此时直接跳过第二步，在 Claude Code 中说：

> "我的课件是扫描版PDF，请直接读取PDF文件中的图片内容来生成复习文档"

Claude Code 具备多模态视觉能力，可以直接从图片中读取公式和文字。

### Q: 提取出的公式显示为乱码？

PDF中的数学公式在文本提取时难免有损坏。技能文件已内置了公式完整性检查机制——Claude Code 在生成文档时会自动识别并修复断裂的公式、丢失的符号。你不需要手动处理。

### Q: 课件中推导步骤不全怎么办？

技能文件的 3.3.2 节定义了完整的推导补全机制。Claude Code 会自动识别课件中被"易证""显然"跳过的步骤，并补全为每一步都有文字解释的完整推导。

### Q: 如何把生成的 .md 文件转成 PDF？

推荐用 Typora 或 VS Code 打开 .md 文件，直接导出为 PDF。也可以让 Claude Code 帮你转换。

### Q: 可以在 macOS / Linux 上使用吗？

完全可以。Python脚本和技能文件都是跨平台的。只需把路径中的反斜杠 `\` 改为正斜杠 `/`。

### Q: 技能文件需要放到特定位置吗？

不需要。只要放在你当前工作的课程目录下，Claude Code 启动时会自动识别。如果你想在任何目录都能使用，可以复制到：

- Windows: `C:\Users\你的用户名\.claude\skills\`
- macOS/Linux: `~/.claude/skills/`
